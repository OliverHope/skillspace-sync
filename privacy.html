Политика конфиденциальности

Skillspace Sync Timeweb — внутреннее приложение владельца школы. Его задача — переносить ведомости результатов из Skillspace в выбранную владельцем Google-таблицу.

Доступ к Gmail

Владелец разрешает доступ через Google OAuth с единственным разрешением gmail.readonly. Технически оно позволяет читать весь почтовый ящик. Логика приложения ограничивает поиск письмами от noreply@skillspace.ru с темой «Файл с прогрессом студентов готов к загрузке».

Перед скачиванием приложение проверяет точное совпадение отправителя и темы, свежесть письма и результаты проверки подлинности, добавленные Gmail. Из подходящего письма получает ссылку на ведомость. Другие письма не используются для переноса данных.

Приложение также проверяет адрес подключённого Gmail-аккаунта. Оно не отправляет письма, не меняет метки, не отмечает письма прочитанными и не удаляет почту.

Какие сведения переносятся

В выбранную Google-таблицу переносятся исходные поля ведомости: имя ученика, email, группа, комментарий, статусы выполнения и выставленные баллы по занятиям. Курсы сопоставляются с отдельными листами таблицы. Приложение не вычисляет новые оценки и не изменяет результаты в Skillspace.

Данные используются для отображения результатов обучения владельцу школы и тем, кому он предоставил доступ к таблице. Они не продаются, не используются для рекламы, сторонней аналитики, рассылок или обучения AI-моделей. Приложение не выполняет AI-обработку.

Хранение и защита

Приложение работает на сервере владельца в Timeweb. Файлы ведомостей, состояние обработки и доступы хранятся в закрытых каталогах. Перенос выполняется по HTTPS в выбранную Google-таблицу; доступ к ней определяется настройками владельца в Google.

В рабочем кэше сохраняются 48 последних исходных файлов ведомостей. Файл незавершённой операции может храниться дольше, пока результат не будет проверен. Отдельные приватные резервные копии используются для восстановления; их срок хранения определяет владелец, а очистка кэша их не удаляет.

Текст писем не архивируется приложением. Для защиты от повторной обработки сохраняются идентификатор письма, время его получения и контрольная сумма файла. Служебные журналы содержат счётчики и безопасные коды ошибок, без токенов, содержимого писем и персональных данных учеников.

Сами эти информационные страницы не содержат трекеров, скриптов или форм сбора данных. При их публикации GitHub Pages обеспечивает доставку страниц в соответствии со своими правилами.

Отзыв доступа и удаление данных

Разрешение можно отозвать на странице связей Google-аккаунта со сторонними приложениями: выбрать Skillspace Sync Timeweb и удалить доступ. После отзыва приложение не сможет продолжать читать Gmail.

Отзыв разрешения сам по себе не удаляет уже сохранённые ведомости, резервные копии или данные Google-таблицы. Для запроса удаления или уточнения состава сохранённых сведений свяжись с владельцем: seazzon1@gmail.com.

Использование Google API

Использование и передача данных, полученных через Google API, соответствуют Google API Services User Data Policy, включая требования Limited Use. Доступ используется только для описанного переноса ведомостей.
