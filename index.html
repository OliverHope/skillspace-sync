Внутреннее приложение школы

Ведомость баллов —
в Google-таблице.

Skillspace Sync Timeweb предназначено для регулярного переноса результатов обучения из Skillspace в отдельную Google-таблицу владельца школы.

Подготовка к запускуПочасовое обновление пока отключено. Эти страницы описывают назначение приложения и правила обработки данных.

Как устроен перенос

  1. 01

    Ведомость Skillspace

    Приложение запрашивает штатную ведомость через кабинет школы.

  2. 02

    Письмо с выгрузкой

    Через Gmail получает письмо о готовой ведомости и проверяет его подлинность.

  3. 03

    Листы по курсам

    Переносит исходные статусы и баллы на соответствующие листы Google-таблицы.

Приложение используется владельцем школы для работы с результатами своих учеников. Оно не предлагает публичную регистрацию или платную подписку.

Gmail подключается с разрешением только на чтение. Приложение не отправляет письма и не изменяет почту. Подробности о доступе, хранении и удалении данных описаны в политике конфиденциальности.
